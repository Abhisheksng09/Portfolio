# Abhishek Singh Negi — Portfolio Website

A responsive, animated single-page portfolio inspired by the bold, playful visual direction in the supplied video. Built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a modern browser. For best results, use a local server (for example, VS Code Live Server).

## Before publishing
- The LinkedIn, GitHub, and LeetCode links currently point to each service's homepage because the resume did not include profile URLs. Replace them in `index.html` with your personal profile links.
- Add project repository/demo URLs when available.
- The page uses Google Fonts from a CDN; if offline, fallback fonts will be used.

## Publish for free
You can deploy this static site using GitHub Pages, Netlify, or Vercel. Upload the contents of this folder (not the ZIP itself if using a file uploader) and follow the host's static-site instructions.

## Files
- `index.html` — content and page structure
- `style.css` — layout, colors, responsive styles, animations
- `script.js` — mobile navigation, scroll reveal, current year
